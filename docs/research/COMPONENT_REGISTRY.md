## Intake checklist

- [ ] The component solves a named requirement.
- [ ] Its source and licence have been reviewed.
- [ ] The selected source is copied only if the terms allow it.
- [ ] Generic catalogue styling has been removed.
- [ ] Hub tokens and Archivo typography are used.
- [ ] No redundant animation or styling dependency remains.
- [ ] Keyboard and focus behavior have been verified.
- [ ] Reduced motion is designed.
- [ ] Mobile performance has been measured.
- [ ] A simpler implementation was considered.
- [ ] The production owner accepted maintenance responsibility.
